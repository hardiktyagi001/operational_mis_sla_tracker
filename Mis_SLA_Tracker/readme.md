Automated Operational MIS & SLA Tracker

Overview

An Excel-based operational MIS reporting system designed to monitor support-ticket workload, SLA performance, turnaround time, and operational status. The project demonstrates how raw operational data can be transformed into structured MIS reports and management dashboards.

Objective
	•	Monitor daily operational ticket volume and status
	•	Track SLA compliance and SLA breaches
	•	Analyze turnaround time (TAT)
	•	Compare workload across priorities and channels
	•	Provide management-ready KPI reporting and dashboards

Tools & Technologies
	•	Microsoft Excel
	•	Pivot Tables
	•	Excel Tables
	•	COUNTIFS / SUMIFS
	•	Data Validation
	•	Conditional Formatting
	•	Excel Charts
	•	MIS Reporting & KPI Analysis

Dataset

The project uses a synthetic support-ticket dataset containing 1,000 operational records.

Key fields include:
	•	Ticket ID
	•	Created Date
	•	Customer ID
	•	Channel
	•	Priority
	•	Category
	•	First Response Time
	•	Resolution Time
	•	Status
	•	Satisfaction

Project Workflow

Raw Data → Data Structuring → SLA & TAT Calculations → KPI Summary → Pivot-Based MIS Reports → Interactive Dashboard

Key Analysis

SLA Monitoring

Defined response and resolution SLA targets based on ticket priority and classified tickets as:
	•	Within SLA
	•	SLA Breached

TAT Analysis

Resolution times were categorized into:
	•	0–1 Hour
	•	1–4 Hours
	•	4–8 Hours
	•	8–24 Hours
	•	24+ Hours

MIS Reports

The workbook includes:
	•	Operational Status Report
	•	SLA Performance by Priority
	•	Channel-wise Status Report
	•	Monthly Ticket Volume & Average Resolution Report

Dashboard

The interactive dashboard provides:
	•	Total Tickets
	•	Open Tickets
	•	Pending Tickets
	•	Resolved Tickets
	•	SLA Breached
	•	SLA Compliance %
	•	Ticket Status Analysis
	•	SLA Performance by Priority
	•	Monthly Ticket Volume Trend
	•	Priority, Channel, and Status filters

Business Value

This project demonstrates practical MIS capabilities including operational reporting, KPI tracking, SLA monitoring, TAT analysis, Pivot-based reporting, and management dashboard development.

Note

SLA thresholds used in this project are portfolio-defined assumptions for analytical demonstration and do not represent policies of the dataset provider.
